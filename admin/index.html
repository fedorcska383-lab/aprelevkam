Редактор сайта

Изменяй текст и контакты. Эта версия сохраняет черновик в браузере и позволяет скачать файл настроек.

Важно: пока сайт размещён как Netlify Drop, редактор не может сам отправлять изменения на публичный сайт. После правок скачай JSON и обнови файлы сайта в Netlify. Автоматическое онлайн-редактирование требует подключить Git и серверное хранилище.
